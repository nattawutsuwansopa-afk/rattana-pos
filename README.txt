Rattana POS v6.18.66 - User Email + POS Password

ระบบเข้าใช้งานใหม่:
- ผู้ใช้ทุกคนสามารถเข้า POS ด้วย อีเมล + รหัสผ่าน POS
- ยังใช้ ชื่อ + PIN ได้เหมือนเดิม
- ใช้งานออฟไลน์ได้บนเครื่องที่เคยมีข้อมูลผู้ใช้แล้ว
- Owner เชื่อม Supabase ครั้งแรกเหมือนเดิม เพื่อดึง/ซิงก์ข้อมูลร้าน

จัดการผู้ใช้:
- Owner เพิ่มผู้ใช้ พร้อมชื่อ / อีเมล / สิทธิ์ / รหัสผ่าน POS / PIN
- Owner ตั้งหรือเปลี่ยนรหัสผ่าน POS ของผู้ใช้ทุกคนได้
- Owner เปลี่ยนอีเมล / PIN / สิทธิ์ / เปิด-ปิด / ลบผู้ใช้ได้
- เพิ่ม/แก้ไข/ลบแล้วอยู่หน้าจัดการผู้ใช้เดิม ไม่เด้งออก
- Owner หลักยังกันลบเพื่อป้องกันล็อกระบบ

ความปลอดภัย:
- รหัสผ่าน POS ไม่เก็บเป็นข้อความ
- ใช้ PBKDF2-SHA256 150,000 iterations + random salt
- จึงไม่สามารถเปิดดูรหัสผ่านเดิมได้
- Owner สามารถ Reset โดยตั้งรหัสใหม่ได้
- ห้ามใส่ Supabase service_role key ใน index.html

การซิงก์:
- email / passwordHash / passwordSalt / PIN อยู่ใน users collection
- ซิงก์ข้ามเครื่องผ่าน Supabase ตามระบบเดิม
- รหัสผ่าน POS ตรวจได้ออฟไลน์หลังเครื่องเคยซิงก์ข้อมูลผู้ใช้แล้ว

ติดตั้ง:
1) อัป index.html ทับ index.html เดิมใน GitHub
2) ไม่ต้องรัน SQL เพิ่ม
3) เปิด https://nattawutsuwansopa-afk.github.io/rattana-pos/?v=61866
4) กด Ctrl+Shift+R หนึ่งครั้ง
5) Owner เข้า ตั้งค่า > ผู้ใช้งานและ PIN
6) แก้ไข Owner และผู้ใช้เดิมเพื่อกำหนดอีเมล + รหัสผ่าน POS
7) ออกจากระบบ แล้วทดสอบเข้าแบบ “อีเมล + รหัสผ่าน”

หมายเหตุ:
- รหัสผ่าน POS เป็นคนละรหัสกับ Supabase Auth
- Supabase Auth ใช้เฉพาะ Owner ตอนเชื่อมเครื่อง/กู้การเชื่อมคลาวด์
