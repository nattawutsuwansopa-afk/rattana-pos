Rattana POS v6.18.65 - User Admin Stay

เพิ่มตามคำขอ:
- Owner ดู PIN POS ของผู้ใช้งานได้จากตาราง
- กด 👁️ ดู / 🙈 ซ่อน PIN ได้
- หน้าแก้ไข Owner/พนักงานสามารถดู PIN ปัจจุบันได้
- Owner ลบบัญชีพนักงานได้จากหน้ารายการหรือหน้าแก้ไข
- ยังกันลบ Owner หลัก เพื่อป้องกันร้านถูกล็อกออกจากระบบ
- ยังกันลบบัญชีที่กำลังใช้งาน
- เพิ่ม/แก้ไข/ลบแล้วอยู่หน้าจัดการผู้ใช้งานเดิม ไม่เด้งกลับเมนูตั้งค่าหรือหน้าหลัก
- ประวัติการขายและ Audit เดิมยังอยู่ แม้ลบผู้ใช้

สำคัญ:
- PIN ของ POS ดูได้ เพราะเป็นรหัสหน้าร้านของระบบนี้
- รหัสผ่าน Supabase/Auth ดูย้อนหลังไม่ได้ เพราะ Supabase เก็บแบบไม่สามารถอ่านรหัสจริงกลับมาได้
