Rattana POS v6.18.63 - User Admin + Store Logo Icon

เพิ่มระบบผู้ใช้งาน:
- Owner/Admin เพิ่มผู้ใช้งานได้จาก ตั้งค่า > ผู้ใช้งานและ PIN
- กรอก ชื่อ / อีเมล / บทบาท / PIN
- แก้ไขอีเมล ชื่อ PIN สิทธิ์ และสถานะได้
- Owner ลบพนักงานได้
- กันลบ Owner หลัก
- กันลบบัญชีที่กำลังใช้งาน
- อีเมลห้ามซ้ำ
- อีเมลซิงก์ข้ามเครื่องพร้อมข้อมูล users ผ่าน Supabase
- พนักงานยังเข้าใช้งานด้วย ชื่อ + PIN ไม่ต้องสมัคร Supabase เอง
- ประวัติขาย/Audit เดิมไม่ถูกลบเมื่อผู้ใช้ถูกลบ

โลโก้หน้าร้าน:
- ใช้ state.config.logo_image เป็นไอคอนแท็บ/เว็บไซต์
- ใช้เป็น apple-touch-icon
- สร้าง Dynamic Web App Manifest จากโลโก้ร้าน
- ถ้ายังไม่มีโลโก้ จะใช้ไอคอน Rattana POS สำรอง
- เปลี่ยนโลโก้ใน ตั้งค่า > ร้าน / โลโก้ แล้วไอคอนอัปเดตทันที
- แนะนำตั้งโลโก้ก่อนติดตั้งเว็บเป็นแอปบน PC เพื่อให้ Edge ใช้โลโก้ร้านเป็นไอคอน

ติดตั้ง:
1) อัป index.html ทับ index.html เดิมใน GitHub repo
2) ไม่ต้องรัน SQL เพิ่ม
3) เปิด https://nattawutsuwansopa-afk.github.io/rattana-pos/?v=61863
4) กด Ctrl+Shift+R หนึ่งครั้ง
5) เข้า Owner > ตั้งค่า > ร้าน / โลโก้ เพื่อเช็กโลโก้
6) เข้า Owner > ตั้งค่า > ผู้ใช้งานและ PIN เพื่อเพิ่ม/ลบ/ใส่อีเมลผู้ใช้

หมายเหตุ:
- อีเมลพนักงานในรุ่นนี้เป็นข้อมูลประจำตัว POS ไม่ใช่ Supabase Auth
- บัญชี Supabase Auth ยังใช้เฉพาะ Owner สำหรับเชื่อมเครื่อง/ซิงก์ร้าน
