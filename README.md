# Rattana POS PWA v6.0 — เลือกทั้งหมด / ลบ / เรียกกลับ

เพิ่มการจัดการแบบหลายรายการในหมวดสำคัญของระบบ POS

- สินค้า: เลือกทั้งหมด / เลือกทีละรายการ / ลบที่เลือก / เรียกกลับรายการที่ลบล่าสุด
- บิลย้อนหลัง: เลือกทั้งหมด / ลบที่เลือก / เรียกกลับ และกำไรคำนวณใหม่ตามยอดขายที่เหลือ
- สมาชิก: เลือกทั้งหมด / ลบที่เลือก / เรียกกลับ
- โปรโมชั่น: เลือกทั้งหมด / ลบที่เลือก / เรียกกลับ
- ผู้ขายสินค้า: เลือกทั้งหมด / ลบที่เลือก / เรียกกลับ
- บิลพัก: เลือกทั้งหมด / ลบที่เลือก / เรียกกลับ
- ประวัติปิดกะ: เลือกทั้งหมด / ลบที่เลือก / เรียกกลับ
- ประวัติการแก้ไข: เลือกทั้งหมด / ลบที่เลือก / เรียกกลับ
- ทุกการลบหลายรายการถามยืนยันก่อน
- เก็บถังเรียกกลับแยกตามหมวดในอุปกรณ์ จึงไม่ทับหมวดอื่น

เมนู ตั้งค่า → รีเซ็ต / ลบข้อมูล ยังคงมี:
- เลือกทั้งหมด
- ลบรายการสินค้า / สต็อก
- ลบยอดขาย / กำไร
- ลบข้อมูลประกอบร้าน
- รีเซ็ตใหม่ทั้งหมด โดยยืนยัน 2 ครั้ง
- เรียกกลับข้อมูลล่าสุด

Backend: ใช้ Backend เดิมได้ ไม่ต้องเปลี่ยน Google Apps Script
