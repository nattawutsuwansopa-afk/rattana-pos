# Rattana POS PWA v4.8 — Mobile Offline Sync Fix

เวอร์ชันนี้แก้กรณีมือถือ/แท็บเล็ตเปิดออฟไลน์แล้วไม่มีรายการสินค้า โดยทำ First Pull จาก Cloud อย่างปลอดภัย และป้องกันอุปกรณ์ใหม่ที่ยังว่างส่งฐานข้อมูลว่างไปทับข้อมูลบน Cloud

## มือถือ/แท็บเล็ตเครื่องใหม่
1. เปิด PWA ตอนมีอินเทอร์เน็ตอย่างน้อย 1 ครั้ง
2. ไปที่ ตั้งค่า → Backup / Cloud Sync
3. ใส่ Apps Script Web App URL และรหัส Sync เดียวกับเครื่องหลัก
4. กด **ดึงรายการจาก Cloud ลงเครื่องนี้**
5. เมื่อดึงสำเร็จแล้ว สามารถปิดเน็ตและใช้งานรายการสินค้าที่อยู่ในเครื่องได้

# Rattana POS PWA v4.7

เวอร์ชันนี้ต่อยอดจาก v4.6 โดยเก็บฐานข้อมูลใน localStorage แบบเดิม จึงอัปเดตทับแล้วข้อมูลเดิมในเบราว์เซอร์ยังอยู่ตามปกติ (ควร Backup JSON ก่อนอัปเดตทุกครั้ง)

## เพิ่มใน v4.7

- ค้นสินค้าฉลาดขึ้น: ชื่อ, บาร์โค้ด, รหัส, หมวดหมู่, คำค้น/ยี่ห้อ และชื่อผู้ขาย
- ช่องคำค้นเพิ่มเติมในข้อมูลสินค้า
- วันหมดอายุสินค้า + จำนวนวันเตือนล่วงหน้า + แจ้งเตือนหน้าแรก
- ผู้ขายสินค้า / เจ้าหนี้: รายชื่อผู้ขาย, ตั้งเจ้าหนี้, ชำระหนี้, ประวัติรายการ และยอดค้าง
- เช็กสต็อกจริง: กรอกยอดที่นับได้แล้วระบบปรับส่วนต่างพร้อม Stock Log
- ปิดยอดประจำวัน / ปิดกะ: บิล, ยอดสุทธิ, เงินสด, QR, คืนเงิน, ส่วนลด, ต้นทุน, กำไร และเงินสดขาด/เกิน พร้อมพิมพ์รายงาน
- ประวัติการแก้ไข: ใครให้ส่วนลด, ยกเลิกบิล, คืนสินค้า, ปรับสต็อก, ตรวจนับ, แก้สินค้า, ผู้ขาย และปิดกะ
- รายงานกำไรจากการขาย แยกวันนี้ / เดือนนี้ / สะสม / รายสินค้า
- จอลูกค้าแบบจอที่สอง: รายการสินค้า, ยอดรวม, ส่วนลด, สมาชิก, QR พร้อมเพย์, โลโก้ร้าน และปุ่มเต็มจอ
- เมนูเครื่องมือใหม่ทั้งหมดถูกรวมไว้ใน “⚙️ ตั้งค่าทั้งหมด” และมีทางลัดบนหน้าแรกสำหรับงานประจำ

## การอัปเดตเว็บ

อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ทับไฟล์เดิมบน GitHub Pages โดยเฉพาะ `index.html` และ `sw.js` จากนั้นปิด PWA แล้วเปิดใหม่ หากยังเห็นหน้าเก่าให้ Refresh หนึ่งครั้ง

## Cloud Sync

โครงสร้างข้อมูล v4.7 เพิ่ม Members, Suppliers, SupplierLedger, ShiftClosures, StockCounts และ AuditLogs หากใช้ Google Apps Script Backend เดิม ควรอัปเดต Backend เป็น v4.7 เพื่อให้ข้อมูลชุดใหม่ซิงก์ไป Google Sheets ด้วย


## เพิ่มเติม v4.9 — ซิงก์อัตโนมัติทุก 15 วินาที
- เมื่อเปิด Cloud Sync ระบบจะตรวจและซิงก์ข้อมูลเบื้องหลังทุก 15 วินาที
- ระหว่างกำลังขาย/มีตะกร้า/กำลังกรอกเงิน/มีหน้าต่างชำระ ระบบจะไม่ rebuild หน้าขาย จึงไม่ดึงโฟกัสหรือทำให้ยอดที่กำลังกรอกหาย
- ถ้ามีข้อมูลใหม่จาก Cloud จะรับเข้าหน่วยความจำและบันทึกในเครื่องก่อน แล้วค่อยแสดงเมื่อหน้าขายอยู่ในจังหวะปลอดภัย
- เมื่อกลับมาออนไลน์หรือกลับเข้าแอป ระบบจะสั่งซิงก์ทันทีอีกครั้ง
- Service Worker ตรวจหาไฟล์ PWA รุ่นใหม่ทุก 15 วินาที แต่จะไม่ reload แอประหว่างกำลังขาย
- ต้องตั้ง Apps Script Web App URL และรหัส Sync ให้ถูกต้องก่อน จึงจะซิงก์ข้ามอุปกรณ์ได้

## เพิ่มใน v5.0 — ปรับหน้าจอตามอุปกรณ์อัตโนมัติ
- ตรวจว่าเป็นมือถือ / แท็บเล็ต / คอม และแนวตั้ง / แนวนอนตอนเข้าใช้งาน
- ปรับขนาด UI และขนาดปุ่มให้เหมาะกับจอสัมผัสโดยอัตโนมัติ
- เมื่อหมุนจอหรือปรับขนาดหน้าต่าง จะปรับใหม่โดยไม่รีโหลดบิลที่กำลังขาย
- มีเมนู ตั้งค่าทั้งหมด > การแสดงผลอุปกรณ์นี้ เพื่อเลือก Auto / Mobile / Tablet / Desktop และขนาด 90–120%
- ค่าหน้าจอเป็น local-only ต่ออุปกรณ์ ไม่ถูก Cloud Sync ไปทับเครื่องอื่น
