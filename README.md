# Rattana POS PWA v6.15 — Full Retail Suite

เพิ่มชุดบริหารร้านเต็มรูปแบบต่อจาก v6.14:

- หลายหน่วยขาย / หลายบาร์โค้ดต่อสินค้า เช่น ชิ้น / แพ็ก / ลัง พร้อมราคาแยกตามหน่วย
- ใบสั่งซื้อ PO → รับสินค้า → เพิ่มสต็อกหน่วยหลัก → คำนวณต้นทุนเฉลี่ย → ตั้งเจ้าหนี้
- ค่าใช้จ่ายร้าน / เงินสดออก และกำไรสุทธิหลังค่าใช้จ่ายในรายงานประจำวัน
- ลูกหนี้ / ขายเชื่อ: วงเงินสมาชิก, ยอดค้าง, รับชำระบางส่วน และประวัติการชำระ
- PIN อนุมัติรายการสำคัญ: ส่วนลด, คืนเงิน, ปรับสต็อก, ขายต่ำกว่าทุน, ขายเชื่อเกินวงเงิน
- ประวัติต้นทุนสินค้า พร้อมที่มาจากการแก้ไขสินค้าและการรับ PO
- ซิงก์ Cloud รุ่น schema 4 รวมการรวมประวัติคืนสินค้าและการรับชำระลูกหนี้จากหลายเครื่อง

## วิธีอัปเดต
1. อัปเดต Google Apps Script เป็น Backend v6.15 และ Deploy → New version ก่อน
2. จากนั้นอัปไฟล์ PWA v6.15 ขึ้น GitHub/Pages ทับรุ่นเดิม
3. เปิด POS ออนไลน์หนึ่งครั้งและกดซิงก์ Cloud

Backend จะสร้างชีตใหม่ PurchaseOrders, Expenses, Receivables และ CostHistory อัตโนมัติ ข้อมูลเดิม v6.14 ไม่ถูกลบ
