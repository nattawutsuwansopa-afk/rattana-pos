# Rattana POS PWA v6.18.6 — Linked Modules

ปรับการเชื่อมโยงเมนูหน้าหลักและศูนย์จัดการร้านให้ใช้ route เดียวกัน พร้อมตรวจสิทธิ์ก่อนแสดงเมนู

- หน้าแรกแสดงเฉพาะเมนูที่ผู้ใช้มีสิทธิ์ใช้งานจริง จึงไม่มีปุ่มที่กดแล้วเข้าไม่ได้
- ตั้งค่า / ศูนย์จัดการร้าน เปิดได้ตามสิทธิ์ของแต่ละโมดูล ไม่บังคับว่าต้องมีสิทธิ์ systemSettings ทั้งหมด
- สินค้า / สต็อก / จัดซื้อ, การเงิน / บัญชี / ปิดยอด, และตรวจสอบ / ระบบร้าน เชื่อมไปฟังก์ชันชุดเดียวกับหน้าหลัก
- สิทธิ์สำคัญยังคงเดิม ไม่ได้ข้าม PIN หรือ permission
- Backend ใช้ v6.16 เดิมได้
