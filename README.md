# Rattana POS PWA v6.18.25 – Payment Voice Flow

ปรับระบบค่าธรรมเนียมบริการโอนเงินให้คิดตามช่วงยอดโอนอัตโนมัติ

- ค่าเริ่มต้น: ยอดโอนไม่เกิน 1,000 บาท = 15 บาท
- ยอดโอนไม่เกิน 2,000 บาท = 20 บาท
- เจ้าของ/ผู้จัดการเพิ่ม ลบ หรือแก้ช่วงยอดและค่าธรรมเนียมได้
- ระบบเรียงช่วงยอดให้อัตโนมัติ
- ถ้ายอดสูงกว่าช่วงสูงสุด ใช้ค่าธรรมเนียมของช่วงสุดท้าย
- หน้าบันทึกโอนคำนวณค่าธรรมเนียมและยอดรับรวมทันทีเมื่อกรอกยอดโอน
- ตารางค่าธรรมเนียมซิงก์ผ่าน Settings เดิม ไม่ต้องเปลี่ยน Backend v6.16


## v6.18.25
- ก่อนชำระ เมื่อเข้าสู่ขั้นตอนรับเงิน ระบบพูด “มียอดต้องชำระ X บาท”
- หลังรับชำระสำเร็จด้วยเงินสดหรือ QR ระบบพูด “ขอบคุณครับ”
- เปิด/ปิดเสียงก่อนและหลังชำระได้จากเมนูตั้งค่าระบบ
- ขายเชื่อไม่เล่นเสียง “ขอบคุณครับ” จนกว่าจะมีการรับเงินจริง
- QR ยังคงมีโทนแจ้งเตือนเดิม แต่ไม่พูดซ้ำ “เงินเข้าแล้ว”
