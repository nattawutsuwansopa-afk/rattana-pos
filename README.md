# Rattana POS PWA v6.18.21

ปรับบริการโอนเงินและเมนูหน้าขาย:
- ย้ายทางเข้า “รายการโอนเงิน” และ “ธนาคาร / ค่าบริการ” มาไว้ที่ ตั้งค่า → เมนูหน้าขาย / คีย์ลัด → เพิ่ม / ลบเมนูในหน้าขาย
- เอาปุ่ม “เงินสดพอดี” ที่ซ้ำในกริดเมนูขวาออก เหลือปุ่ม “รับเงินพอดี” จุดเดียวใต้แป้นตัวเลข
- เพิ่มตัวย่อธนาคารภาษาอังกฤษ เช่น BBL, KBANK, KTB, SCB, BAY, TTB, GSB, BAAC, UOB, CIMBT, KKP
- ตัวย่อแก้ไขได้ในหน้าตั้งค่าธนาคารและซิงก์ผ่าน Settings เดิม
- แสดงตัวย่อในรายการโอน แบบฟอร์มเลือกธนาคาร และใบรับบริการ

Backend: ใช้ v6.16 เดิมได้
