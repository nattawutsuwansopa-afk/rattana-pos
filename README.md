# Rattana POS PWA v6.15.2 — ประวัติสินค้า / รับเข้า

ต่อยอดจาก v6.15.1 โดยเพิ่มประวัติสินค้าแบบละเอียดสำหรับตรวจสอบย้อนหลังว่า:

- สินค้าเข้าวัน/เวลาใด
- รับเข้าจำนวนเท่าไร และสต็อกก่อน → หลังเท่าไร
- รับจาก PO ใด / ผู้ขายรายใด
- ใครเป็นคนบันทึกหรือรับสินค้า
- ทำรายการจากอุปกรณ์/เครื่องใด
- ใครเป็นคนสร้างรายละเอียดสินค้า และใครแก้รายละเอียดล่าสุด
- ดูประวัติรายสินค้าได้จากหน้าสินค้า หรือดูรวมจากเมนูตั้งค่า

## เมนูใหม่

ตั้งค่าทั้งหมด / เครื่องมือร้าน → `📜 ประวัติสินค้า / รับเข้า`

กรองได้ตามวันที่ สินค้า ประเภทรายการ และค้นหาจากชื่อสินค้า / PO / ผู้ขาย / ผู้บันทึก / ชื่อเครื่อง

## การบันทึกข้อมูลใหม่

ตั้งแต่ v6.15.2 เป็นต้นไป Stock Log, PO, ประวัติต้นทุน และรายละเอียดสินค้าจะบันทึกชื่อผู้ใช้ + User ID + ชื่ออุปกรณ์ + Device ID เพิ่มเติม

ข้อมูลเก่าก่อน v6.15.2 จะแสดงเท่าที่เคยมีบันทึกไว้ และอาจไม่มีชื่ออุปกรณ์หรือผู้สร้างรายละเอียดครั้งแรก

## Backend

ใช้ Backend v6.15 เดิมได้ ไม่ต้อง Deploy Backend ใหม่ เพราะใช้ Collections เดิม: Products, StockLogs, AuditLogs, PurchaseOrders และ CostHistory
