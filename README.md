# Rattana POS PWA v6.3 — สินค้าโปรโมชั่น

เพิ่มเมนู **🔥 สินค้าโปรโมชั่น** สำหรับกำหนดราคาพิเศษรายสินค้า

- กำหนดราคาโปรโมชั่นแยกจากราคาปกติ
- ตั้งวันเริ่ม/วันสิ้นสุดได้
- เปิด/ปิดโปรโมชั่นได้
- เมื่ออยู่ในช่วงโปรโมชั่น หน้าขายใช้ราคาพิเศษอัตโนมัติ
- หน้าค้นสินค้าแสดงป้าย 🔥 โปร และราคาปกติขีดทับ
- เมนูสินค้าโปรโมชั่นแสดงรายการโปรทั้งหมด พร้อมสถานะ กำลังโปร / รอเริ่ม / หมดเขต
- เจ้าของ/ผู้จัดการแก้ไขหรือลบโปรโมชั่นได้
- แคชเชียร์มองเห็นรายการโปรและกดขายสินค้าโปรได้
- ข้อมูลโปรเก็บอยู่ในข้อมูลสินค้า จึงซิงก์ผ่าน Backend เดิมได้

ไม่ต้องเปลี่ยน Google Apps Script Backend จากรุ่นที่ใช้อยู่
