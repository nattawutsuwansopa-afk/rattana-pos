# Rattana POS PWA v6.18.3 — Fit Screen Dialogs

ปรับการเปิดเมนูและรายการให้ดูง่ายขึ้นตามขนาดหน้าจอ

- เมื่อเปลี่ยนหน้าหลัก ระบบเลื่อนกลับด้านบนอัตโนมัติ
- กดเมนูเดิมซ้ำจากแถบบน จะกลับไปด้านบนทันที
- หน้าต่างรายการ/ตั้งค่าต่าง ๆ เปิดชิดด้านบนของจอและจำกัดความสูงตามหน้าจอ
- ถ้ารายการยาว จะเลื่อนเฉพาะภายในหน้าต่าง ไม่ต้องเลื่อนหน้าเว็บด้านหลัง
- หน้ารับชำระเงินยังคงจัดกึ่งกลางเพื่อใช้งานสะดวก
- รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์ด้วย 100dvh
