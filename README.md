# Rattana POS PWA v6.6 — Custom Sale Settings / Shortcuts / Thank-you Sound

## เพิ่มใน v6.6
- ตั้งค่าเมนูหน้าขายได้: เปิด/ซ่อนปุ่มแต่ละเมนูจากหน้า Settings และเรียกกลับได้ทุกเมื่อ
- ตั้งคีย์ลัด F1–F12 สำหรับคำสั่งหลัก เช่น เลือกสินค้า สมาชิก พักบิล เรียกบิล โปรโมชั่น รับชำระ สแกนกล้อง ตั้งค่า และจอลูกค้า
- ค่าคีย์ลัดและการแสดงเมนูเก็บใน state ของร้าน จึงซิงก์ผ่าน Cloud ไปทุกอุปกรณ์
- ปรับขนาดตัวอักษร 80–140% แยกตามอุปกรณ์
- ปรับความสว่างหน้าตาโปรแกรม 65–130% แยกตามอุปกรณ์ (เป็นความสว่างของหน้าเว็บ ไม่ใช่ไฟหน้าจอฮาร์ดแวร์)
- เสียงหลังรับชำระ เปิด/ปิดได้ และเลือก “ขอบคุณครับ” หรือ “ขอบคุณค่ะ”
- ท้ายใบเสร็จแสดงโลโก้ร้านอีกครั้งเมื่อมีการตั้งโลโก้
- ใช้ Backend v6.4 เดิมได้

> คีย์ลัดทำงานบนคอมโดยตรง และบนมือถือ/แท็บเล็ตเมื่อเชื่อมต่อคีย์บอร์ดจริงหรือคีย์บอร์ดภายนอก ส่วนปุ่มคำสั่งบนจอสัมผัสยังใช้งานตามปกติ

# Rattana POS PWA v6.5 — Adaptive Price Labels / Barcode Printing

## เพิ่มใน v6.5
- พิมพ์ป้ายราคาได้จากมือถือ แท็บเล็ต และคอม ผ่านหน้าพิมพ์มาตรฐานของอุปกรณ์
- เลือกเครื่องพิมพ์ที่ระบบรองรับ เช่น AirPrint, Mopria, Network Printer หรือไดรเวอร์บนคอม
- ขนาดป้าย: 40×25, 50×30, 58×40, 70×40, 80×50 มม., A4 3 คอลัมน์ และกำหนดเอง
- ขนาดบาร์โค้ด: อัตโนมัติ / มาตรฐาน / กระชับ / ใหญ่
- เลือกทั้งหมด / เลือกหลายสินค้า / พิมพ์หลายป้ายพร้อมกัน
- กำหนดจำนวนสำเนาต่อสินค้า 1–50
- ตรวจรูปแบบบาร์โค้ดอัตโนมัติ EAN-13 / EAN-8 / UPC / CODE128
- ราคาโปรโมชั่นแสดงบนป้ายอัตโนมัติ
- การตั้งค่าป้ายเก็บเฉพาะอุปกรณ์ ไม่ซิงก์ไปทับเครื่องอื่น
- ใช้ Backend v6.4 เดิมได้

> เว็บจะเปิดหน้าพิมพ์ของระบบเพื่อเลือกเครื่องพิมพ์ที่อุปกรณ์นั้นเชื่อมต่ออยู่ ไม่สามารถข้ามหน้าพิมพ์และสั่งพิมพ์เงียบไปยังเครื่องพิมพ์ทุกยี่ห้อได้โดยตรง

# Rattana POS PWA v6.4 — Durable Cloud / Offline Merge

รุ่นนี้เปลี่ยน Cloud Sync จากการเลือกฐานข้อมูลทั้งก้อนว่า “เครื่องไหนใหม่กว่า” เป็นการรวมข้อมูล **รายรายการ** เพื่อให้คอม มือถือ และแท็บเล็ตทำงานพร้อมกันได้ปลอดภัยขึ้น

## การทำงาน

- เปิด POS แล้วตรวจข้อมูล Cloud อัตโนมัติ เมื่อเครื่องนั้นเคยตั้ง URL + รหัส Sync แล้ว
- เพิ่ม / แก้ / ขายสินค้า: บันทึกในเครื่องก่อนทันที แล้วส่ง Cloud เบื้องหลังประมาณ 0.65 วินาที
- ตรวจข้อมูลจากอุปกรณ์อื่นทุก 15 วินาที
- ออฟไลน์ยังขายต่อได้ และมีคิวรายการรอส่งใน `localStorage`
- ออนไลน์กลับมาแล้วส่งคิวอัตโนมัติ
- แต่ละ record มี `updatedAt` และ `deviceId`
- การซิงก์รวมข้อมูลตาม `id` จึงเก็บบิลใหม่จากหลายเครื่องได้พร้อมกัน
- สต็อกใช้ `stockSyncBase + StockLogs` เพื่อรวมการขาย/รับเข้า/คืน/ปรับสต็อกจากหลายเครื่อง
- แต้มสมาชิกผสานประวัติแต้มตาม event ID แล้วคำนวณยอดคงเหลือใหม่
- การลบเป็น **Soft Delete** ผ่าน Tombstones และเก็บสำเนาใน **ถังขยะ Cloud**
- มีปุ่มเรียกกลับจากถังขยะ Cloud
- รองรับ Backend v6.4 สำหรับสำรอง Google Sheet รายวันและสำรองทันที
- หน้าขายไม่ถูกรีเฟรชระหว่างกำลังขาย/รับเงิน; ข้อมูลใหม่จะรอจังหวะปลอดภัยก่อน render

## อัปเกรด

1. อัป Backend v6.4 ใน Google Apps Script ก่อน
2. Deploy เป็น New version โดยใช้ `/exec` เดิม
3. อัปไฟล์ PWA v6.4 ขึ้น GitHub Pages ทับรุ่นเดิม
4. อัปทุกอุปกรณ์ให้เป็น v6.4 ใกล้เคียงกัน
5. ใน ตั้งค่า → Backup / Cloud Database กด “ซิงก์ตอนนี้” 1 ครั้ง
6. กด “เปิดสำรองรายวัน” 1 ครั้ง

เครื่องใหม่ยังต้องใส่ Web App URL + รหัส Sync ครั้งแรก 1 ครั้ง เพราะไม่ควรฝังรหัสลับไว้ใน GitHub Public
