# Rattana POS PWA v6.12 — Alerts / Data Check / Central Trash / Daily Report

อัปเดตจาก v6.11 โดยเพิ่ม 4 เครื่องมือในเมนูตั้งค่า โดยคงระบบเดิมทั้งหมดไว้:

- 🔔 แจ้งเตือนหน้าร้าน: สินค้าใกล้หมด, ใกล้/หมดอายุ, Cloud ยังไม่พร้อม/ออฟไลน์/ซิงก์มีปัญหา และรายการรอส่ง พร้อมไอคอนกระดิ่งบนแถบด้านบนและสรุปบนหน้าแรก
- 🔍 ตรวจข้อมูลผิดปกติ: ตรวจบาร์โค้ดซ้ำ, ชื่อสินค้าซ้ำ, ราคาขาย/ราคาโปรโมชั่นต่ำกว่าทุน และสต็อกติดลบ โดยไม่แก้ข้อมูลอัตโนมัติ
- 🗑️ ถังขยะกลาง: รวม Soft Delete จากทุกอุปกรณ์ กรองตามหมวด เลือกทั้งหมด/หลายรายการ และเรียกกลับพร้อมซิงก์ Cloud (เจ้าของร้าน)
- 📊 รายงานประจำวัน: เลือกวันที่ ดูยอดขายสุทธิ, กำไร, จำนวนบิล, คืนเงิน, เงินสด/QR/เครดิต, ส่วนลด, ต้นทุน และ Top 10 สินค้าขายดี พร้อมพิมพ์ A4

การตั้งค่าแจ้งเตือนอยู่ใน `state.settings.frontAlerts` และซิงก์ไปทุกอุปกรณ์ผ่านระบบ Durable Cloud เดิม

## Backend
ใช้ Backend v6.9 เดิมได้ ไม่ต้องเปลี่ยน Apps Script เพราะไม่ได้เพิ่ม Collection ใหม่ ใช้ข้อมูล `settings`, `products`, `sales`, `recycleBin` และ `tombstones` ที่มีอยู่แล้ว

## ติดตั้งอัปเดต
แตก ZIP แล้วอัปโหลดไฟล์ภายในโฟลเดอร์ขึ้น GitHub Pages ทับเวอร์ชันเดิม โดยเฉพาะ `index.html` และ `sw.js` จากนั้นเปิด POS ออนไลน์หนึ่งครั้งเพื่อให้ Service Worker อัปเดต Cache เป็น v6.12
