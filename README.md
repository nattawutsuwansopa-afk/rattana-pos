# Rattana POS PWA v5.6 — สแกนบาร์โค้ดเข้าหน้าขาย

## เพิ่มใหม่
- หน้าขายกด **📷 สแกนกล้อง** แล้วสแกนบาร์โค้ดเพื่อเพิ่มสินค้าเข้าบิลได้ทันที
- เมื่ออ่านสำเร็จจะแสดง **✓ สแกนสำเร็จ** และเลขบาร์โค้ด แล้วปิดหน้ากล้องอัตโนมัติประมาณ 0.65 วินาที
- ถ้าสินค้ามีอยู่แล้ว จะเพิ่มสินค้าเข้าบิลทันที (สแกนซ้ำเพิ่มจำนวน)
- ถ้าบาร์โค้ดยังไม่มี และผู้ใช้เป็นเจ้าของ/ผู้จัดการ ระบบจะเปิดหน้า **เพิ่มสินค้า** พร้อมใส่บาร์โค้ดให้อัตโนมัติ
- เครื่องสแกนบาร์โค้ดแบบ USB/Bluetooth ที่ยิงเข้าในช่องบาร์โค้ดหน้าขายยังใช้ได้ตามเดิม
- ใช้ Backend เดิมได้ ไม่ต้องเปลี่ยน Google Apps Script
