# Rattana POS PWA v6.18.17

## Responsive Fit + ปิดกะ/ปิดวันในหน้าขาย

- ปรับหน้าจอให้ยืด/ย่อตามขนาดอุปกรณ์และความสูงของ viewport มากขึ้น
- ป้องกันเนื้อหาหลักล้นออกด้านข้างของจอ
- ปรับหน้าขาย เมนูขวา ตาราง และช่องรับเงินตามจอคอม/แท็บเล็ต/มือถือ
- เพิ่ม breakpoint สำหรับจอคอมที่มีความสูงน้อย เพื่อย่อปุ่มเมนูขวาและแป้นตัวเลขให้อยู่ในจอ
- เพิ่มปุ่ม `🧮 ปิดยอด/ปิดกะ` และ `🔒 ปิดยอดประจำวัน` ในเมนูด้านขวาหน้าขาย
- ปุ่มทั้งสองเปิด/ปิดได้จาก `ตั้งค่า > เมนูหน้าขาย / คีย์ลัด`
- แสดงปุ่มเฉพาะผู้ใช้ที่มีสิทธิ์ `shiftClose`
- Backend ใช้ v6.16 เดิม
