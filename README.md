# Rattana POS PWA v6.11 — System Health / Printer / Permissions / Device Name

อัปเดตจาก v6.10 โดยเพิ่มเครื่องมือดูแลหลายอุปกรณ์ในเมนูตั้งค่า:

- 🩺 ตรวจสุขภาพระบบ: อินเทอร์เน็ต, Cloud Sync, HTTPS, กล้อง/สแกน, ระบบพิมพ์, พื้นที่เก็บข้อมูล, Service Worker/PWA พร้อมปุ่มทดสอบ
- 🖨️ ตั้งค่าเครื่องพิมพ์แยกแต่ละอุปกรณ์: ใบเสร็จ 58 มม., 80 มม., A4, จำนวนสำเนา, ระยะขอบ, พิมพ์อัตโนมัติหลังขาย และเชื่อมไปตั้งค่าป้ายราคา
- 🔐 สิทธิ์พนักงานละเอียด: เจ้าของกำหนดสิทธิ์รายคน เช่น เพิ่ม/แก้/ลบสินค้า, ปรับสต็อก, ส่วนลด, คืน/ยกเลิกบิล, รายงาน, โปรโมชั่น, ผู้ขาย, ปิดกะ, พิมพ์ป้าย, Cloud, ตั้งค่าระบบ ฯลฯ สิทธิ์อยู่ใน Users และซิงก์ผ่าน Cloud
- 📱 ตั้งชื่ออุปกรณ์: เช่น “แคชเชียร์ 1”, “แท็บเล็ตคลัง”, เก็บเฉพาะเครื่องนั้น และชื่อถูกบันทึกลง Audit Logs และบิลใหม่ที่เครื่องสร้าง
- 🧾 ใบเสร็จใช้ขนาดกระดาษตามอุปกรณ์และยังคงโลโก้ร้านหัว/ท้ายใบเสร็จ

## Backend
ใช้ Backend v6.9 เดิมได้ เพราะ `users` และ `auditLogs` อยู่ใน Durable Cloud Sync แล้ว ส่วนการตั้งค่าเครื่องพิมพ์และชื่ออุปกรณ์เป็นค่าประจำเครื่อง

> หมายเหตุ: เว็บไม่สามารถอ่านรายชื่อเครื่องพิมพ์ที่ติดตั้งได้โดยตรง ให้เลือกเครื่องพิมพ์จาก Print Dialog ของระบบปฏิบัติการ
