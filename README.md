# Rattana POS PWA v6.18.4 — Transfer in POS

- ย้ายเมนู “โอนเงินธนาคาร” ออกจากหน้าหลัก
- เพิ่มปุ่ม “🏦 โอนเงิน” ในเมนูด้านขวาของหน้าขายสินค้า
- ปุ่มโอนเงินอยู่แถวล่างร่วมกับ “รับเงินพอดี” และ “ตั้งค่า” เพื่อไม่เพิ่มความสูงของแผงเมนู
- ยังควบคุมการแสดง/ซ่อนได้จาก “ตั้งค่าเมนูหน้าขาย”
- ตรวจสิทธิ์ `manageBankTransfers` ก่อนเปิดรายการโอนเงิน

Backend: ใช้ v6.16 เดิม ไม่ต้องเปลี่ยน
