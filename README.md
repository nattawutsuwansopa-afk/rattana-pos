# Rattana POS PWA v6.18.9 — Settings Workspace

ปรับเมนูตั้งค่าเป็น Workspace เต็มหน้าจอจริง:
- ทุกเมนูในศูนย์ตั้งค่าเปิดเป็นหน้า/แท็บภายใน Workspace เดียวกัน
- มีแถบหัวคงที่: กลับ, ชื่อหน้าปัจจุบัน, breadcrumb, เมนูตั้งค่า, หน้าหลัก
- เมนูสินค้า/สถิติ/บิล/ป้ายราคาไม่กระโดดออกจากศูนย์ตั้งค่า
- popup ภายในเมนูตั้งค่าถูกแปลงเป็นหน้าใน Workspace
- ปุ่มกลับย้อนหน้าก่อนหน้า และหน้าเนื้อหาเลื่อนเฉพาะพื้นที่กลาง
- ปิดศูนย์ตั้งค่าแล้วกลับแท็บเดิมที่เปิดก่อนเข้าตั้งค่า

Backend: ใช้ v6.16 เดิม
